# 信以为真（I Believe）

一款关于“被相信的事物会成真”的叙事模拟游戏。你讲出的故事会在人们之间流传、变形，长成节日、地名和神灵。完整设计见 [docs/GDD.md](docs/GDD.md)。

当前进度：里程碑 1，纯文字传播沙盒（计划见 [docs/PLAN-M1.md](docs/PLAN-M1.md)）。

## 本地运行

需要 Node.js 22 或更新版本。

```bash
npm install
npm run dev     # 启动开发服务器
npm test        # 运行测试
npm run build   # 构建到 dist/
```
